# World Muslim Population — 2026 edition

Interactive map of the share and number of Muslims by country, province, district and city.
Open `index.html` through a web server (GitHub Pages, Netlify, etc.) — opening it directly from disk
won't load the data files.

Data: Pew Research Center 2020 national baseline, plus national censuses and registers (sources shown on each
place's card). Concept after Edin Radončić (2015).
